# Foodereum – Secure SDLC Case Study

Blockchain-based food supply chain system developed during my Bachelor of Engineering (Computer Science & Engineering) and later reassessed through an individual MS Cybersecurity capstone from an application-security perspective.

This repository presents the complete Secure SDLC lifecycle — system design, development, research publication, security assessment, and secure re-engineering.

---

## 🔍 Portfolio Objective

This case study demonstrates how trust is established, validated, and enforced in a decentralized application when transitioning from a development mindset to an adversarial security perspective.

It is intended to showcase:

- Application Security assessment methodology  
- Trust-boundary identification in Web3 systems  
- Business-impact–driven vulnerability analysis  
- Secure SDLC implementation in a real project  

---

## 🧱 Project Lifecycle

**Undergraduate (B.E. – Computer Science & Engineering)**  
- Designed and developed a blockchain-based food supply chain traceability system as part of a team of three under faculty supervision  
- Implemented smart contracts, web application workflows, and stakeholder lifecycle management  
- Awarded **Best Project** at the Dayananda Sagar College of Engineering Project Open-Day (June 2022)

**Research Contributions**  
- IEEE Conference Publication:  
  *Foodereum: A Blockchain-based Authenticated Solution for Food Supply Chain*  
- IJEAT Journal Publication:  
  *A Literature Review on Consortium Blockchain Consistency to Improve Traceability in Food Supply Chain System*

**Master’s (MS Cybersecurity – Capstone Project)**  
- Individually performed a full application-security assessment of the same system with prior team approval  
- Identified authorization, workflow validation, and trust-enforcement gaps  
- Redesigned controls using Secure SDLC principles  

---

## 🛡️ Security Focus Areas

- Application-layer authorization enforcement  
- Role-based lifecycle validation  
- Protection against unauthorized state transitions  
- Elimination of client-side trust assumptions  
- Alignment of blockchain immutability with real access control
